# Station 5 — Art Generation Prompts

Approved reference: ../../BRANDGUIDE.md. All references are style-only. Source of truth for mechanics: ../../Stations/Station_5_Collapsing_Armory_Corridor_of_the_Taboo_Word.md.

**Current state:** the PNGs in this folder are SVG stand-ins drawn by `draw_station5_art.py` (brand palette, ink outlines, glow), because no reference-capable image generator was available in this session. They are flatter than the approved Station 2 painterly style. To upgrade, generate each asset below with an image generator, attaching the listed reference, and save it over the PNG with the same filename. The print packs pick up the new file automatically.

**Rules for every prompt:** never write the taboo word in any image. Penalty art shows only the hazard, so no card hints at the password, the pipe or rack order. No watermark.

Text-heavy props are built as HTML/SVG by `build_station5.py` and do **not** need AI art: corridor mat, rack tags, ceiling word cards, ceiling tracker and slider, archway plaque, sump blueprint and penalty card frames.
